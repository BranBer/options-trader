# Epic 31 / 32 UX Audit — 2026-04-02

## Scope

Audit focused on the portfolio attribution and diagnostics surfaces introduced across Epic 31 and Epic 32, with emphasis on operational debugging workflows, scrolling behavior, and state clarity.

## Fixed Immediately

### Diagnostics trace list clipping and paginator overlap

- Problem: expanding the final alert trace in the diagnostics tab could be visually clipped by the card container, and the `Load More Alerts` button could appear behind the last few expanded accordions.
- Root cause: the recent-traces card used a constrained scroll region inside a parent card that defaults to `overflow-hidden`, while the paginator lived outside the scrolled trace flow.
- Fix shipped: the trace card now allows visible overflow, and the trace list plus paginator share the same scrollable flow so expanded items do not collide with pagination controls.

## Epic 31 Findings

### High priority

- Completed: the decision funnel now emphasizes the dominant drop-off, stage retention, and relative funnel width instead of only raw counts.

### Completed since audit opened

- Attribution correlation and missed-opportunity panels no longer dead-end. They now deep-link into diagnostics with contextual filters, including pipeline-gap, missed-opportunity, and per-ticker trace views.

### Medium priority

- Missed-opportunity rows compress too much context into a single line on smaller viewports. They need clearer reason affordances, timestamps, and a stronger action path.
- Correlation rows show lifecycle facts but do not surface a clear severity or "needs investigation" cue for high-quality rejected or unevaluated alerts.

## Epic 32 Findings

### High priority

- Completed: diagnostics now shows an explicit active-filter summary strip so the current debugging window is visible and removable without reconstructing state from the controls.
- Completed: pinned traces now support a compact compare mode for tighter layouts, reducing stage-detail noise when comparing multiple alerts.

### Medium priority

- Completed: failure clusters and top reasons now apply diagnostics filters directly from the side rail.
- Dashboard entry points are now present, but attribution-driven entry points inside the portfolio page still need to be added to complete the Epic 31 → Epic 32 workflow.

## Recommended Order

1. Add attribution-to-diagnostics deep links from Epic 31 panels.
2. Add an active-filter summary strip to the diagnostics tab.
3. Add quick-apply interactions from failure-cluster and top-reason summary cards.
4. Consider a compact compare layout for 2-3 pinned traces on narrower screens.
